# Estrutura de pastas

| Caminho | Conteúdo |
| --- | --- |
| `frontend/index.html` | Documento inicial, viewport, CSS e módulo principal. |
| `frontend/assets/` | Imagens, ícones e fontes. |
| `frontend/views/pages/` | Templates HTML de telas. |
| `frontend/views/components/` | Templates HTML reutilizáveis. |
| `frontend/views/layouts/` | Estrutura compartilhada da aplicação. |
| `frontend/css/base/` | Reset, tokens, tipografia, estilos globais e utilitários. |
| `frontend/css/components/` | Estilos de componentes. |
| `frontend/css/pages/` | Estilos específicos de telas. |
| `frontend/css/layouts/` | Estilos da estrutura compartilhada. |
| `frontend/css/main.css` | Entrada e ordem dos imports de CSS. |
| `frontend/js/base/` | Configurações públicas e constantes. |
| `frontend/js/components/` | Comportamento dos componentes. |
| `frontend/js/pages/` | Apresentação e eventos das páginas. |
| `frontend/js/layouts/` | Montagem de layouts. |
| `frontend/js/routes/` | Registro de rotas e navegação. |
| `frontend/js/services/` | Acesso a recursos externos à apresentação. |
| `frontend/js/utils/` | Funções auxiliares. |
| `frontend/js/app.js` | Inicialização. |
| `frontend/controllers/` | Coordenação de ações. |
| `frontend/models/` | Dados e regras de negócio. |
| `backend/` | Reserva para o servidor futuro. |
| `docs/` | Documentação do projeto. |

Exemplo de correspondência: `views/pages/inicio.html`, `css/pages/inicio.css`, `js/pages/inicio.js` e `controllers/inicio-controller.js`.
