# Visão geral

O StudyUp é um projeto voltado à organização dos estudos, com interface pensada primeiro para celular. O escopo detalhado das funcionalidades será definido durante o desenvolvimento.

## Estado inicial

- HTML, CSS e JavaScript puro, sem dependências externas.
- Módulos JavaScript nativos do navegador.
- Tela inicial mínima e tela para endereços desconhecidos.
- Navegação por hash (`#/inicio`).
- Cabeçalho e navegação inferior reutilizáveis.
- Bases de estilos, configurações e armazenamento local.

## A definir

Funcionalidades de estudo, identidade visual definitiva, autenticação, persistência no servidor, API e tecnologia de backend.

Esta base não implementa login, cadastro, tarefas, sincronização, instalação como PWA ou funcionamento offline.
